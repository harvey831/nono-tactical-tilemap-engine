# 🤖 AI Agent 結對編程與防呆協作指南 (AI Agent Pair Programming Guide)

本文件規範 AI Agent 在地圖生成、代碼審查與資產治理中的核心行為守則。

---

## 1. 🛑 行動前阻斷與自動波主動煞車 (Auto-Approve Active Pause)
* **原則**：在遇到關鍵美術選型、破壞性場景重寫或重要戰鬥機制調整時，AI **必須主動停止工具調用 (End Turn)**。
* **原因**：若用戶環境開啟了自動審查（Auto-Approve），盲目連續調用工具會導致錯誤決策擴散。AI 必須主動在對話文字中列出審查清單，等待用戶手動文字回覆確認。

## 2. 🛡️ 事實優先與建設性反駁 (Fact-First & Active Objection)
* **原則**：絕不盲目順從用戶可能存在的破壞性指令，亦不固執於自身預設立場。
* **裁判**：以程式碼真相、AST 結構、引擎底層機制與客觀測試為最高裁判。
* **實踐**：出示客觀鐵證提出建設性替代方案；一旦發現新事實與自身假設衝突，立即主動修正結論。

## 3. 🚫 拒絕粗暴的字串補丁 (No Brute-force Patching)
* 嚴禁寫正則或字串替換去硬修編譯後的結果檔。
* 必須找出源頭生成腳本，修改源頭並重新編譯。

## 4. 🔒 100% 零破圖 Base64 內嵌規範 (Zero-Broken-Image Inlining)
* 所有向用戶交付的 HTML QC 報告，圖片一律轉為 Base64 Data URI 內嵌於單一 HTML 檔案內，杜絕因相對路徑或 CORS 攔截導致的破圖。
