## 3. NONO 接手前必須知道的三件事

### 3.1 `needs_review: true` 共 22 題——選項本身是圖或公式

考選部放射科題本有一類題目，**四個選項是圖或數學式**（sinogram、影像遮罩、假體影像、照野平坦性公式），純文字抽取只抽得到 `A. B. C. D.` 四個空標記。

處理方式（依交接單第 5 節「含圖題怎麼辦」）：選項填佔位字串 `（此選項為圖／公式，請看原卷 PDF）`，`has_figure` 與 `needs_review` 都設 `true`。出題引擎預設排除含圖題，**不會出成錯題**。要納入的話得先從原卷補圖。

清單（21 題圖／公式選項 + 1 題含不可轉碼字元）：

```text
111-1-C-072  111-1-F-040  111-2-C-066  111-2-C-068  111-2-C-069
111-2-D-077  112-2-C-036  112-2-E-080  112-2-F-057  113-1-D-077
```

這 22 題同時也是 validate 的另一類警告「有重複的選項文字」的來源（四個佔位字串一樣）。

### 3.2 `has_figure: true` 共 297 題——但 `figures` 全部是空的

`has_figure` 來自澄羽的 `figure_keyword` 關鍵字偵測，**只是提示，不保證抓全**。圖檔一張都還沒從 PDF 抽出來，所以 `figures` 全空。validate 共 319 條 WARN（297 條含圖題無圖 + 22 條佔位選項重複），**全是 warning 不是 error，exit 仍為 0**。

### 3.3 題幹與選項是 PDF 自動抽取，出題前要看原卷

澄羽在 `VALIDATION.md` 已聲明、珂洛複核同意：

* 上下標、數學式、跨頁頁首、圖片、文字閱讀順序可能在抽取時遺失或錯位
* `answer` 取自答案表（有更正檔者優先），**批改時仍需逐條核對官方公告文字**
* 全庫 4,800 題的 `tag_status` 都是 `keyword_candidates_require_tutor_review`——知識點候選標籤可能來自選項而非主考點，**NONO 標註時要核對主考點，不要照抄**

`answer_note` / `answer_revised` 已從澄羽的 `correction_notes` 帶入。

## 4. 答案更正／送分：35 題的正確語意（**批改前必看**）

考選部 25 份更正公告影響 **35 題**。澄羽那份把這 35 題的 `answer_token` 一律改成 `#`，
但 `#` 在本 repo schema 的定義是「一律給分（送分題）」——**只有 14 題真的是這樣**。

| 類型 | 題數 | 官方公告長相 | `#` 對不對 |
|---|---|---|---|
| 一律給分 | 14 | 「第32題一律給分」 | ✅ 對 |
| 部分給分 | 20 | 「第46題答Ｂ或Ｄ者均給分」 | ❌ **會多給分**——答 A、C 的人不該給分 |
| 答案更正 | 1 | 「第52題答Ｃ給分」 | ❌ 根本不是送分，是答案從 Ｄ 改成 Ｃ |

已處理：
* `115-1-F-052` 的 `answer` 從 `#` 改成 **`C`**（原標準答案 Ｄ）
* 35 題的 `answer_note` 全部重寫成**該題自己那一句**公告，並附原標準答案與可給分集合
  （澄羽的 `correction_notes` 是整份公告的文字，同一份公告裡別題的內容也會被塞進來）
* 20 題部分給分仍標 `#`，因為 schema 的 `answer` 只能放單一字母，`additionalProperties: false`
  也不允許我自己加欄位

**給 NONO 的建議**：schema 加一個選填欄位表達複數正解，例如

```json
"answer_accepted": { "type": "array", "items": { "enum": ["A","B","C","D"] } }
```

加了之後這 20 題就能填 `answer_accepted: ["B","D"]`，批改才會正確。
在那之前，出題引擎請把這 20 題排除計分，或依 `answer_note` 逐題處理，**不要當成一律給分**。
