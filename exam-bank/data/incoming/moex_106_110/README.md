## 已經轉好了：`data/bank/106-1-A.jsonl` ～ `110-2-F.jsonl`

跟 111～115 那批同一套規則轉的（同一支切分函式、同一套答案語意），所以兩批可以直接混在一起出題。
`incoming/README.md` 寫的是「原樣送、轉檔 NONO 來」——這裡的原始文字照送，但 bank 也一起轉好了，
理由是庫裡已經有 111～115 的成品，只送原料會讓題庫一半是成品一半是原料，反而更難對。
**要重轉隨時可以**：工具是 `exam-bank/tools/import_moex_pdfs.py`，吃 PDF 直接產 bank，可重複執行。

```bash
python tools/import_moex_pdfs.py \
    --sources "C:/GPTfile/姐姐大人/study_radiographer/sources" --years 106-110 \
    --out-dir ../data/bank --text-out ../data/incoming/moex_106_110/text \
    --corrections-out ../data/corrections_parsed.json
```

（那支工具需要本機的 PDF，雲端沒有網路也讀不到大叔硬碟，所以由珂洛在本機跑。）
