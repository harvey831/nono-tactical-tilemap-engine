# NONO cloud 題庫入口

大叔已確認需求：使用民國 111～115 年、每年兩次、醫事放射師六科的官方國考真題，依他學到的章節測試理解程度。

1. 讀 `README.md` 與 `NONO_TUTOR_BRIEF.md`。
2. 依 `CATALOG.md` 選取官方試卷；按 `index/question_topics.csv` 搜尋主題候選題，再由 NONO 審核是否真的符合已學範圍。
3. 考前核對原題與必要圖表；考後以官方答案與更正備註批改。
4. 每次只考一題，先不揭答案，請大叔說明理由。將實際作答記錄於本 cloud 資料夾內的 `attempts.csv`，並更新 `learning_progress.csv`。

本資料夾是使用者指定的交付位置，之後學習紀錄以此處為準。姐姐工作區保留製作副本，日後更新不得整包覆蓋這裡已新增的作答與進度紀錄。

這次只交付題庫檔案，沒有啟動 NONO、建立定時考試或更改其人格設定。資料夾被放入本機 `nono_google_cloud` 不等於已確認 Google Drive 同步完成，也不等於已加入 Gemini Gem Knowledge；手機端需確認能實際讀到所選卷與 brief。
