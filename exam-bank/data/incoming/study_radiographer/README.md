# 醫事放射師國考學習題庫

建立日期：2026-09-09（香港時間）

目的：讓 NONO 依使用者實際學到的章節挑選國考原題，分開評估作答正確率、理由與計算能力。

## 五年範圍與狀態

- 來源為考選部官方「考畢試題查詢平臺」；暫依使用者所稱「考畢網」作此解讀。
- 收錄民國 111～115 年（2022～2026），每年兩次，醫事放射師六科：60 份官方原卷、60 份標準答案及官方頁面提供的 25 份更正答案，共 145 份 PDF。
- 題目全部來自官方真題，沒有把 AI 自編題混入原卷。章節標籤及教學規則是額外整理。
- 原卷與搜尋索引分開：`CATALOG.md` 按年份與科目找卷；`index/question_topics.csv` 按主題找候選題。自動抽取文字及關鍵字標籤尚未全數人工逐題校對，NONO 出題前需對照原卷、確認章節與必要前置知識。
- `PHYSICS_TOPIC_INDEX.md` 保留先前閱讀原題建立的 19 題物理主題索引；全庫抽取檢查結果見 `VALIDATION.md`。
- 尚未取得使用者本學期實際進度；過往談過的主題不等於已熟練。沒有任何已完成測驗或能力分數。
- 本資料包供 NONO 讀取使用；尚未啟動 NONO 或修改其設定。

官方入口：https://wwwq.moex.gov.tw/exam/wFrmExamQandASearch.aspx?e=115020&y=2026

## 使用方法

把 `NONO_TUTOR_BRIEF.md` 交給能讀取此資料夾的 NONO，再告訴她目前學到的範圍，例如：

> 我學到 β 衰變與半衰期，尚未學核種平衡。請讀這個資料包，只考已學部分，每次一題，先不要揭答案；算完再請我說明理由，最後記錄弱點。

手機或無法讀本機檔案的 NONO，需要另外提供 brief、所選原卷與答案；不能只貼一個她無法存取的本機路徑。

## 整理與批改原則

1. 題目以官方原卷為準，保留年份、場次、科目、题號與完整選項；跨頁選項、負號、上下標、圖表必須核對原頁。
2. OCR/文字抽取僅供搜尋，不可默認為已校對題庫。缺圖或無法辨讀就暫停該題，不補造內容。
3. 官方答案與 NONO 自行撰寫的解析分開標示。法規題與臨床規範題若涉及版本變動，另查現行一手資料並區分當年考試答案。
4. 更正題可保留做討論，但「一律給分」題不納入能力評估。多答案題按官方備註批改。
5. 國考原題、改編題、自編題清楚區分。改編題不可沿用原題答案鍵，需重算。
6. 原題做過後的答對率與首次作答分開，避免把記住答案當理解。
